# Microfrontend Architecture with Vite

This is a microfrontend architecture with Vite and Jotai Atoms for client-side rendering.

This is for learning purposes only.

## Run with Docker Compose

Install [Docker Desktop](https://www.docker.com/products/docker-desktop/) and run:

```sh
docker compose up --build
```

Open the shell application at http://localhost:5000. The Cart and Products remotes are available
at http://localhost:5001 and http://localhost:5002 respectively. Stop the stack with
`docker compose down`.
